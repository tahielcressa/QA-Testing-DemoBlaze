## 🎯 Objetivo

Validar las funcionalidades principales de **DemoBlaze** (tienda demo de ventas online) y documentar el proceso de testing de forma clara y reproducible, de manera que los casos cargados en este repositorio **sirvan como base para la automatización** con herramientas como Selenium, Cypress o Playwright.

## 📋 Contenido

| Área | Alcance |
|---|---|
| ✅ **Casos de prueba** | Cubren registro, login, catálogo, carrito, checkout y contacto |
| 🐞 **Reportes de bugs** | Defectos encontrados con pasos de reproducción y severidad |
| 📝 **Formato** | Estandarizado y listo para convertirse en scripts automatizados |

## 🔍 Funcionalidades cubiertas

- **Registro y login** de usuarios.
- **Navegación** por categorías de productos.
- **Carrito de compras**: agregar, listar y eliminar productos.
- **Checkout**: flujo de compra y mensajes de confirmación.
- **Contacto**: envío del formulario.
